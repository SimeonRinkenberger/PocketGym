# PocketGym — public site

The static pages behind https://simeonrinkenberger.github.io/PocketGym/ : the landing page, the return pages the
PocketGym app opens after billing and Strava, and the assets those pages use. GitHub Pages serves `docs/` from `main`.

The app's own code lives in a private repository; this copy of its `docs/` folder is published from there with
`tools/site/publish.sh`. Edit there, not here.

Questions or problems with the app: https://github.com/SimeonRinkenberger/spotter/issues
